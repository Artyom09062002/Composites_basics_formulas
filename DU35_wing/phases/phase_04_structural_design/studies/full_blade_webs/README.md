# Full-Blade Sandwich-Web Study

This CAD-based study maps the measured DU35 section into the 61.5 m NREL 5 MW
blade and checks two source-based sandwich shear webs.

The earlier `RF = 0.0058` result belonged to a superseded monolithic-wall
screen without the documented 50 mm core and separated DB faces. The Sandia
`2 DB / 50 mm foam / 2 DB` baseline instead gave global shear-buckling
`RF = 1.285` and governing face-shear `RF = 0.784`.

The tested static reinforcement of 3 DB layers per side from 10.25 to 38.95 m
raised the minimum static reserve factor to `RF = 1.078`. The corrected
CAD/source mapping of the DU35 trailing-edge panel gave `RF = 2.227`.

The geometry exchange used by later phases is `data/cad_web_geometry.csv`.
The associated FreeCAD files and presentation are stored in the project Drive.
