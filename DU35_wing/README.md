# DU35 / NREL 5 MW Blade Example

This folder contains the full-scale blade project, organised by engineering
phase. Every phase keeps its own calculation code, inputs, verification and
selected numerical outputs.

```text
phase_01_design_basis        requirements, assumptions and acceptance criteria
phase_02_aerodynamics        NREL planform, BEM and external loads
phase_03_materials           source-traceable material database
phase_04_structural_design   layup, beam screening and DU35 CAD-based studies
phase_05_fea                 beam/shell-equivalent static, modal and buckling FE
phase_06_optimization        web/support DoE and surrogate screening
phase_07_fatigue             20-year damage and combined sensitivity closure
phase_08_final               integrated final checks, workbook and CAD manifest
```

The FreeCAD model and presentations are stored in the project Google Drive;
only calculation-relevant files, selected spreadsheets and the final model GIF
are tracked here.
