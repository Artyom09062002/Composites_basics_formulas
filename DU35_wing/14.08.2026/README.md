# Day 4 — полноразмерная NREL 5 MW лопасть

## Результат

Создана CAD-based surface-модель лопасти длиной 61,5 м с 19 сечениями и двумя
измеряемыми sandwich shear webs. Старый результат `RF = 0,0058` относился к
неподходящей монолитной модели стенки без 50-мм сердечника и разнесённых
DB-обшивок, поэтому он не используется как решение по реальной конструкции.

Проверка source-based Sandia-стенки `2 DB / 50 mm foam / 2 DB` дала:

- global shear buckling: `RF = 1,285` — PASS;
- governing face shear: `RF = 0,784` — FAIL.

Для обеих стенок добавлена зона `3 DB layers/side` на `10,25–38,95 м`.
Минимальный итоговый запас стал `RF = 1,078` — PASS. Текущая рабочая модель:
`cad/NREL5MW_61p5m_CADBasedBlade_v3_ReinforcedWebs.FCStd`.

Corrected CAD/source mapping панели DU35 TE также проходит: `RF = 2,227`.
Проверки проекта: `29/29 OK`.

## Реальная неудача

Первая попытка построить закрученную стенку одной четырёхугольной гранью между
сечениями закончилась `OCCError`: вершины неплоского quad не лежат в одной
плоскости. Исправление — разбиение каждого участка на две треугольные shell-грани.

## Компактный состав

- `cad/` — исходная и усиленная CAD-модели;
- `code/nrel5mw_blade_integration.py` — связь DU35 с общей моделью лопасти;
- `code/nrel5mw_sandwich_web_assessment.py` — расчёт стенок и limit states;
- `code/freecad_builder.py` — одна воспроизводимая сборка обеих CAD-моделей;
- `tests/` — две независимые группы тестов;
- `results/Day4_results.xlsx` — все таблицы в одной книге по отдельным листам;
- `results/cad_web_geometry.csv` — единственный машинный обмен CAD → расчёт;
- `figures/` — общий CAD-вид, DU35-сечение и график RF;
- `sources/SOURCES.md` — реестр источников;
- `sources/cad_inputs.zip` — станции и координаты профилей для пересборки CAD.

## Ограничения и следующий шаг

Это screening surface-модель, а не production-ready solid и не
сертификационная shell-FEA. Следующий расчёт должен обновить массу и жёсткость
по CAD v3 и проверить стенки shell FEA с реальным шагом поперечных опор.
